
# Inferencia Estadística (`statistical-inference-course`)

Material interactivo, apuntes y recursos visuales del curso de **Inferencia Estadística**.

🌐 **Ver página en vivo:** [https://camilabautistaa.github.io/statistical-inference-course/](https://camilabautistaa.github.io/statistical-inference-course/)

---

## Contenido del repositorio

* **`index.html`**: Presentación / guía interactiva principal publicada mediante GitHub Pages.
* **Temas principales**:
  * Distribuciones muestrales y estadísticos suficientes.
  * Estimación puntual (Máxima Verosimilitud, Método de los Momentos, Cota de Cramér-Rao).
  * Estimación por intervalos de confianza.
  * Pruebas de hipótesis (Lema de Neyman-Pearson, Razón de Verosimilitud).
